DEBUG (rapide) :
  • Temps : 2-3 minutes
  • Taille : ~50 MB
  • Optimisations : Désactivées
  • Usage : Tests et développement
  • Commande : npm.cmd run tauri build -- --debug

RELEASE (optimisé) :
  • Temps : 10-20 minutes
  • Taille : ~10-15 MB
  • Optimisations : Maximales
  • Usage : Distribution aux utilisateurs
  • Commande : npm.cmd run tauri build
